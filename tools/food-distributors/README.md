# Food distributors graphics: generator and tests

Source for `graphics/food-distributors/card-1.js` to `card-4.js`, page /industries/food-distributors, Graphic Key `food-distributors`. All four cards are built. Card 4 shipped in v1.41.0 (manifest `[4]`). The release that adds cards 1 to 3 lists `[1, 2, 3, 4]`, bumps the version and is tagged on the merged main commit.

* **Frame:** the same as Functional beverage. `build.py` uses `tools/automotive/frame_auto.py` on the shared Watch and Try it frame (`tools/electronics/frame.py`, 716 by 640 window, step arrows, ripple hotspots, Studio badge and popover, Replay, aria labels, reduced motion), with the first action at 900 ms.
* **Build:** `python3 tools/food-distributors/build.py` rebuilds all four, or pass card numbers.
* **Card 1: Stock Available to Sell.** Record form with a side summary. Background 1. Look up Penne Pasta 20 lb Case (read only), switch Main warehouse to Cold room, place the preset 300 case order SO-3124, open the red warehouse total, create PO-4471 for 1,000 cases from Rossi Imports. Main: bins B-12-3 (700, 0, 500), B-14-1 (500, 0, 400), DK-2 (0, 600, 0), so 1,200 + 600 minus 900 = 900. The order adds 200 and 100 to committed (300 in total), so 1,200 committed and 600 available, under the 800 reorder point. Cold room: C-01-2 (250, 0, 60), C-03-1 (150, 0, 40), so 400 in stock, 100 committed, 300 available. Open orders add up to committed (300 + 250 + 350 = 900; cold 100).
* **Card 2: Lot Tracking & Customer Traceability.** List and detail. Background 2. Search L-24-0817 (read only), open the lot (B-12-3, expiry Mar 15, 2027, 2,000 received), Shipments tab (Greenfield Market 600, Harbor Deli 450, Corner Pantry 250 = 1,300 shipped, 700 left), open the Rossi Imports certificate, Trace order SO-3110 (L-24-0817 200 + L-24-0822 100 = 300). Allocated to open orders: SO-3110 200 and SO-3112 120, so 380 free.
* **Card 3: Quotes, Orders & Price Lists.** Stage chain (Quote, Sales order, Reserved, Status link) with running totals. Background 3. Start quote for Greenfield Market (read only), apply the price list (Penne $35.00, break to $33.50 at 100 or more, 200 cases = $6,700.00; Olive Oil $88.00, no break, 50 cases = $4,400.00; total $11,100.00, against $12,200.00 at list), convert to SO-3110, reserve 200 and 50 (available 900 to 700, 180 to 130), send the status link. Prices are kept in cents.
* **Card 4: Scan Verified Picking & Shipping.** Board layout (pick list column, scan panel, shipment column, running totals strip). Background 4.
  1. Open pick list: SO-3110's three lines, entered as Penne, Lime, Lavender, are sorted into bin order A-02-1, A-04-2, B-12-3.
  2. Scan item: the Lime case matches A-02-1, so the line turns green (40 cases).
  3. Scan item: the Lime barcode is scanned for the Lavender line. The warning names both items and shows both pictures, and the line stays open.
  4. Complete pick, which takes 3 clicks in Try it: scan the Lavender case, scan the Penne case (both marked `data-pick`), then Complete pick. 270 cases picked. On hand Lime 500 to 460, Lavender 300 to 270, Penne 700 to 500. In Watch, the two rescans play as the cursor moves to Complete pick.
  5. Generate: Packing slip PS-3110 and Bill of lading BOL-3110.
* **Read only demos:** every input (item, lot number, customer, sales order, case barcode) is prefilled, `readonly`, `tabindex="-1"`, gray and ignore the pointer. The barcode shows the case in hand for the current line. There's no typing, no typing animation, no sample buttons and no input errors.
* **Tests:** `test_card1.py` to `test_card3.py` assert each README sum in Python and on screen (available per row, committed changes by exactly 300, the flag only under 800, received = shipped + remaining, the trace lots, line totals, the break on line 1 only, reserved = ordered), with the same start screen, timing, edge, width, keyboard and mouse checks as card 4.
* **Card 4 tests:** `test_card4.py` (through `fd_tests.py`, the Automotive harness) first asserts the README's numbers in Python: ascending bin order, 40 + 30 + 200 = 270, each on hand falls by its picked quantity, and valid, distinct UPC check digits. Then it checks the start screen, timing, Watch and Try it with every caption and number, that a wrong scan never confirms a line and Complete pick stays disabled, Replay, the arrows, the Studio popover, reduced motion, edges at four widths, 390 and 340 px, a keyboard only walk, and a mouse only walk at 604 and 358 px (Done in 7 clicks).
* `shots.py 4 [card widths]` saves a screenshot per step.

Run with `pip install playwright pillow`. Set `PW_CHROME` to a Chromium binary already on the machine.

The backgrounds are copies of `graphics/functional-beverage/bg-1.jpg` to `bg-4.jpg`, one per card (604 by 540, progressive JPEG, about 50 KB). All names, quantities and readings are invented sample data for illustration.
