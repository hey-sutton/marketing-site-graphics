# Nut processing graphics: generator and tests

Source for `graphics/nut-processing/card-1.js` to `card-4.js`, page /industries/nut-processing-software, Graphic Key `nut-processing`. All four cards are built. The manifest, the version, the loader and the release tag are left to the release owner: the release adds `"nut-processing": [1, 2, 3, 4]` to `manifest.json`, bumps the version and is tagged on the merged main commit. The CMS slug is `nut-processing-software`, so the item's Graphic Key must be set to `nut-processing` (the loader's slug fallback would find nothing).

* **Frame:** the same as Food distributors. `build.py` uses `tools/automotive/frame_auto.py` on the shared Watch and Try it frame (`tools/electronics/frame.py`, 716 by 640 window, step arrows, ripple hotspots, Studio badge and popover, Replay, aria labels, reduced motion), with the first action at 900 ms.
* **Build:** `python3 tools/nut-processing/build.py` rebuilds all four, or pass card numbers.
* **Card 1: Raw Intake & Grade Records.** Record form with a side summary. Background 1. Receive truckload NP-0711 (read only): Harlan Orchards, Merced County block 14, Nonpareil 23/25, scale ticket ST-5521 gross 42,000 minus tare 14,000 = 28,000 lb net. Record moisture (5.2 and 23/25, read only) against the 6.0 maximum: within spec. Attach lab result VAL-3318: accepted. Record moisture for NP-0712 (Tule Bend Farms, Carmel 25/27, 7.1 read only): above 6.0, held at the dock and struck from put away. Incoming lots: 3 lots in 2 grades (NP-0709 Delmar Ranch 24,400, NP-0711 28,000, NP-0712 26,700 held), 52,400 lb to put away, 79,100 lb in.
* **Card 2: Stage Yield & Loss.** Stage chain. Background 2. Open raw lot L-2417 (read only), 20,000 lb in shell. Shelling 12,800 out (36.0% loss), roasting 12,160 (5.0%), blanching 11,552 (5.0%), packed 11,552. Running yield 64.0, 60.8, 57.76; total 57.76% = 0.64 x 0.95 x 0.95, 8,448 lb lost. Compare origins: A 2026 57.8% (this lot), B 2026 55.0% (L-2433), A 2025 58.1%, B 2025 56.4%. Check expected yield flags only B 2026, under 56%.
* **Card 3: Bulk Bins & Lot Genealogy.** List and detail. Background 3. Open bin B-101 (read only): 4,000 lb of lot L-A from NP-0711. Blend with B-102 (3,000 lb of L-B from NP-0709) into B-200, lot L-C, 7,000 lb at 57.1% and 42.9%. Split into PK-5120 (1,000 retail 5 lb packs, 5,000 lb) and BK-2210 (2,000 lb bulk tote), 7,000 lb in total. Trace PK-5120 to NP-0711 and NP-0709. Customers: Pinecrest Snack Co. 400, Morning Trail Granola 350, Sunbank Grocers 250 = 1,000 packs. The room total stays 7,000 lb through the blend and the split.
* **Card 4: Allergen Segregation & Scheduling.** Board. Background 4. Open the Line 1 week (read only): R1 free from, R3 tree nut, R4 free from, R2 peanut. Cleaning 30 + 45 + 60 = 135 minutes. Move the peanut run after R1: preview R1, R2, R3, R4 at 60 + 120 + 45 = 225, +90 minutes, shown before anything is committed (the board keeps its order). Sign off the R1 to R3 cleaning (D. Moreno, read only): R3's Start run enables only then. Start R3: R4 stays blocked until the R3 to R4 cleaning (45 minutes) is signed.
* **Read only demos:** every input is prefilled, `readonly`, `tabindex="-1"`, gray and ignores the pointer. No typing, no typing animation, no sample buttons, no input errors. Every step is one click.
* **Tests:** `test_card1.py` to `test_card4.py` (through `np_tests.py`, the Automotive harness) first assert the README's numbers in Python (net = gross minus tare, held only above 6.0, a held lot left out of put away; each loss percent, total yield = product of stage yields, the flag only under 56; blend = sum of bins, retail + bulk = 7,000, both deliveries in the trace; 135, 225, +90, the blocked run enabling only after the sign off), then check each on screen, plus the start screen (inputs prefilled and read only, nothing derived, no editable field), timing, Watch and Try it, Replay, the arrows, the Studio popover, reduced motion, edges at four widths, 390 and 340 px, a keyboard only walk and a mouse only walk at 604 and 358 px (Done in 5 clicks).
* `shots.py N [card widths]` saves a screenshot per step.

Run with `pip install playwright pillow`. Set `PW_CHROME` to a Chromium binary already on the machine.

The backgrounds are copies of `graphics/food-distributors/bg-1.jpg` to `bg-4.jpg`, one per card (604 by 540, progressive JPEG, about 50 KB). All names, quantities and readings are invented sample data for illustration.
