# Meat and poultry processing graphics: generator and tests

Source for `graphics/meat-poultry-processing/card-1.js` to `card-4.js`, page /industries/meat-poultry-processing, Graphic Key `meat-poultry-processing`. All four cards are built. The manifest, the version, the loader and the release tag are left to the release owner: the release adds `"meat-poultry-processing": [1, 2, 3, 4]` to `manifest.json`, bumps the version and is tagged on the merged main commit.

* **Frame:** the same as Nut processing. `build.py` uses `tools/automotive/frame_auto.py` on the shared Watch and Try it frame (`tools/electronics/frame.py`, 716 by 640 window, step arrows, ripple hotspots, Studio badge and popover, Replay, aria labels, reduced motion), with the first action at 900 ms.
* **Build:** `python3 tools/meat-poultry-processing/build.py` rebuilds all four, or pass card numbers.
* **Card 1: Yield Loss by Stage.** Stage chain. Background 1. Open batch JRK-3310 (read only, 1,000 kg raw): spec 45.0%, 450 kg expected. Log drainage 950, then Log trim 900 and Log drying 420 (one step, two clicks: Log trim carries data-pick). Loss lines: drainage 50, trim 50, drying 480 = 580; 1,000 minus 580 = 420. Compare: 42.0% actual against 45.0%, 30 kg under spec.
* **Card 2: Lot Traceability to the Customer.** List and detail. Background 2. Search BEEF-24-0731 (read only): Prairie Ridge Beef, 2,400 kg received. Runs tab: JRK-3310 1,000, GRD-3314 600, SAU-3318 400 = 2,000 used, 400 left. Customers tab: FG-7701 420 (Lakeside Market 250, Ridge Foods 170), FG-7704 570 (Ridge Foods), FG-7708 380 (Lakeside Market); Lakeside 630, Ridge 740. Dates tab: pack Oct 28, use by Nov 27. Trace order beside SO-8841 (FG-7701 170 + FG-7704 570): two runs, one supplier lot.
* **Card 3: Carcass & Primal Planning.** Board. Background 3. Open orders for week 47 (read only, 3 orders). Show cuts: ribeye 252, brisket 266, trim 1,700 kg (by ship day). Work back: order over yield per carcass (12, 14, 85), rounded up, 21, 19, 20. Check stock: on hand 36, 0, 85, net need 216, 266, 1,615, carcasses 18, 19, 19. Create PO: 19 carcasses (the largest), ribeye 228 kg, 12 kg over the net 216.
* **Card 4: Raw to Ready to Eat Runs.** Record form with a side summary. Background 4. Open order JRK-3310 (read only): raw and ready to eat stages. Issue meat: BEEF-24-0731 falls from 2,400 to 1,400 kg. Start run: spice blend 25 kg, cure 5 kg, 8,400 bags and 70 cartons deduct on their own. Record weight (420, read only): 420,000 g / 50 g = 8,400 bags, 8,400 / 120 = 70 cartons. Finish: new lot FG-7701, pack Nov 2, use by Feb 2.
* **Read only demos:** every input is prefilled, `readonly`, `tabindex="-1"`, gray and ignores the pointer. No typing, no typing animation, no sample buttons, no input errors. Every step is one click, except card 1 step 3 (Log trim, then Log drying).
* **Tests:** `test_card1.py` to `test_card4.py` (through `mp_tests.py`, the Automotive harness with the read only checks from Nut processing) first assert the README's numbers in Python, then check each on screen, plus the start screen (inputs prefilled and read only, nothing derived, no editable field), timing, Watch and Try it, Replay, the arrows, the Studio popover, reduced motion, edges at four widths, 390 and 340 px, a keyboard only walk and a mouse only walk at 604 and 358 px.
* `shots.py N [card widths]` saves a screenshot per step.

Run with `pip install playwright pillow`. Set `PW_CHROME` to a Chromium binary already on the machine.

The backgrounds are copies of `graphics/food-distributors/bg-1.jpg` to `bg-4.jpg`, one per card (604 by 540, progressive JPEG, about 50 KB). All names, quantities and readings are invented sample data for illustration.
